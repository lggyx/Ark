# ARK 可行性评估报告

> **结论**：需调整参数后可行

## 1. 硬件可行性

### 1.1 OnePlus 8T 硬件参数

| 组件 | 规格 | 备注 |
|------|------|------|
| SoC | Qualcomm Snapdragon 865 (7nm) | ARM64，支持 NEON |
| CPU | 1x2.84GHz + 3x2.42GHz + 4x1.8GHz (Kryo 585) | 大核可承担 LLM 推理 |
| RAM | 12GB LPDDR5 | 可用 ~8GB（系统占用） |
| 存储 | 256GB UFS 3.1 | 可扩展 microSD |
| 屏幕 | 6.55" AMOLED 120Hz | 阅读体验良好 |
| 电池 | 4500mAh | 实测待机功耗需验证 |

### 1.2 LLM 推理可行性

**目标模型**：Llama-3-8B-Instruct (Q4_K_M 量化)

| 指标 | 估算值 | 来源 |
|------|--------|------|
| 模型文件大小 | ~4.7GB | HuggingFace 社区数据 |
| 内存占用 | ~5.5GB (Q4_K_M) | llama.cpp 官方 benchmark |
| 推理速度 | ~15-25 tok/s (SDM865) | 公开 benchmark (llama.cpp, ARM64) |
| 上下文窗口 | 4096 tokens | 模型配置 |

**结论**：12GB RAM 可运行 Q4_K_M 量化模型，但内存余量紧张（~6.5GB 给系统+知识库）。建议：
- 使用 Q3_K_M 或 Q2_K 量化降低内存占用
- 关闭系统动画和后台服务
- 使用 Termux + proot-distro 减少 overhead

## 3. 续航与太阳能仿真模型

### 3.1 使用模式参数

| 场景 | CPU/GPU 负载 | 屏幕 | 每小时 AI 推理次数 | 每小时阅读分钟数 |
|------|--------------|------|-------------------|------------------|
| 轻度使用 | 低 | 亮 | 5-10 次 | 30-60 分钟 |
| 中度使用 | 中 | 亮 | 20-30 次 | 10-20 分钟 |
| 重度使用 | 高 | 亮 | 50+ 次 | 0 分钟 |

### 3.2 电池续航估算

| 状态 | 功耗 | 4500mAh 续航 |
|------|------|--------------|
| 待机（黑屏） | ~0.5W | ~150 小时 |
| 阅读（屏幕亮） | ~1.5W | ~50 小时 |
| AI 推理 | ~6-8W | ~9-12 小时 |
| 混合使用（加权平均） | ~3W | ~25 小时 |

### 3.3 太阳能充电估算

| 太阳能板 | 额定功率 | 实际充电（晴天） | 实际充电（阴天） |
|----------|----------|------------------|------------------|
| 5W | 5W | ~3W | ~0.5W |
| 10W | 10W | ~6W | ~1W |
| 20W | 20W | ~12W | ~2W |

### 3.4 离线自持天数曲线

**场景**：中度使用（每天 20 次 AI 推理 + 30 分钟阅读）

| 太阳能板 | 纯储能续航 | +5W 太阳能 | +10W 太阳能 | +20W 太阳能 |
|----------|------------|------------|-------------|-------------|
| 无 | 25 小时 (~1 天) | 1.5 天 | 2.5 天 | 5+ 天 |
| 5W | — | 3+ 天 | 5+ 天 | 无限* |
| 10W | — | 5+ 天 | 无限* | 无限* |
| 20W | — | 无限* | 无限* | 无限* |

*无限 = 日发电量 ≥ 日耗电量

**结论**：
- 20W 太阳能板可完全支撑中度使用场景
- 5W 太阳能板仅能延长待机/轻度使用
- 建议标配 20W 折叠太阳能板

## 4. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| SDM865 推理速度不足 | 响应慢 | 使用更小模型（1.5B/3B）或 Q2 量化 |
| 内存不足 | 系统卡顿 | 关闭后台服务，使用轻量桌面环境 |
| 太阳能充电不稳定 | 断电风险 | 20000mAh 储能电池作为缓冲 |
| 3D 打印外壳精度 | 防护失效 | 多次测试打印，调整公差 |
| 知识库时效性 | 信息过时 | 定期更新 ZIM 包（需联网时） |

## 5. 结论

**结论：需调整参数后可行**

### 可行条件

1. **模型调整**：使用 Llama-3-8B Q3_K_M 或更小模型（3B/1.5B），降低内存占用
2. **功耗控制**：关闭后台服务，使用轻量系统配置
3. **太阳能配置**：标配 20W 折叠太阳能板 + 20000mAh 储能电池
4. **内容包精简**：优先 WikiMed + Appropedia + 核心技术手册，总大小控制在 10GB 以内

### 不建议的方案

- 使用 Q4_K_M 全精度模型（内存压力过大）
- 5W 太阳能板作为主力电源（阴天无法自持）
- 包含完整离线地图（3.5GB 过大，可降级为省级）
