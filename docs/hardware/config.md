## ⚡ 功耗预算

### 运行状态
| 状态 | 功耗 | 续航（储能电池）|
|------|------|----------------|
| 待机 | 0.5W | ~150小时 |
| 轻度使用（阅读） | 2W | ~37小时 |
| AI推理 | 6-8W | ~9-12小时 |
| 太阳能充电 | -15W | 充电中 |

### 日常场景估算
- **晴天**: 20W太阳能 → 可全天运行并充电
- **阴天**: 5W太阳能 → 维持待机，晚间靠储能
- **夜晚**: 纯储能 → 约10小时AI使用
