## 3D打印部件

### 打印清单

| 部件 | 材料 | 时间 | 支撑 |
|------|------|------|------|
| 主外壳 | PETG | 6h | 否 |
| 前面板 | PETG | 2h | 否 |
| 太阳能支架 | ASA | 4h | 是 |
| 电池托盘 | PETG | 2h | 否 |
| 散热格栅 | PETG | 1h | 否 |
| 按键盖板 | TPU/软胶 | 1h | 否 |

### 打印参数

```
层高: 0.2mm
壁厚: 3层
填充: 30%
打印温度: 235°C (PETG) / 250°C (ASA)
热床温度: 80°C
速度: 50mm/s
回抽: 3mm @ 40mm/s
```
